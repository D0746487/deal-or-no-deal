# Deal or No Deal

適合手機操作的 18 張牌小遊戲。

## 玩法

1. 選一張底牌，保留到最後。
2. 七回合依序開 5、4、3、2、1、1、1 張牌。
3. 每回合主持人口頭報價，網站直接按 Deal 或 No Deal，不需輸入金額。
4. Deal 後仍可查看剩餘牌面；遊戲保持成交狀態。
5. 選「重新開始」會重新隨機分配 18 筆金額。
6. 金額表下方顯示未揭曉金額的平均值（遊戲進行中包含底牌），作為報價與選擇的參考。
7. 「開牌動畫」可切換直接揭曉或抿牌。動畫開啟時，按住紙張向任意方向拖動，數字會隨紙張折回逐步露出；中途放手會復位，拖開後正式開牌。已抿開後關閉視窗也會計入開牌。鍵盤可按 Enter 揭曉。

金額：1,000 × 6，1,500、2,000、2,500、3,000、4,000、5,000、6,000、7,000、8,000 各一筆，10,000 × 3。
